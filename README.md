# My-Metal-Shelf
## Introduction

This project was one of my first welding projects that I've done. This metal shelf I created is for my new 3d printer, some storage area, and to hang off this smaller shelf for tools. This metal shelf serves no function other than storing "things" and being structurally intact. 

## Materials Needed

Welding set-up
* Four of 68 inches long 1 inch metal tubes
* Six of 34 inches long angle iron
* Seven of 22 inches long angle iron
